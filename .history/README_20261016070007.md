# Bagtas GuideMap

A beginner-friendly React + Tailwind CSS HCI prototype for an offline barangay mapping and locator app.

## Requirements

- Node.js (LTS recommended)
- npm

## Run locally

1. Extract the project folder.
2. Open a terminal inside `bagtas-guidemap`.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL printed in the terminal.

## Build for deployment

```bash
npm run build
```

The production build will be created in `dist`. For Vercel, use the Vite framework preset, build command `npm run build`, and output directory `dist`.

## Screens

- Home
- Search
- Map / Route
- Location Details
- Emergency Directory
- Confirmation

## HCI principles demonstrated

- **Consistency:** shared layout, buttons, typography, and location cards.
- **Visibility:** strong primary actions and large Quick Access category buttons.
- **Feedback:** search result messages and a confirmation screen after actions.
- **User control:** persistent Back and Home controls plus return/cancel paths.
- **Error prevention:** empty search submissions are caught and a helpful message appears.
- **Clear navigation:** screen name appears in the header and React Router controls routes.
- **Visual hierarchy:** blue primary actions, grouped cards, labels, and whitespace.

## Prototype limitations

- The map and route are static illustrations, not live GPS.
- Location distances and walking times are sample estimates.
- External photo URLs require internet access. Replace them with local files in `public/images` if you need image assets to work offline.
- The local emergency numbers are placeholders and must be replaced with verified contact numbers before real-world use.
- The app does not automatically call emergency services or start real navigation.
